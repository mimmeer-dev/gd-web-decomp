# Geometry Dash Web Decompilation*

This project aims to decompile and then *(maybe)* later mod the web copy of Geometry Dash to add more features to make it a usable Geometry Dash clone.

It is based on the web version of Geometry Dash, found at [the site linked here: https://geometrydash.com/](https://geometrydash.com/).

This'll take a while... but we've got 56k lines of code to figure out, so why not help?
To help, you can simply fork this project, clone it (or not), decompile it a bit more, and push it as a pull request!

***decompilation here in this case just means deobfuscating JavaScript and making it readable so we can build on it.**
