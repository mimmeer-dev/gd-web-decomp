# Tools for Geometry Dash Web Decompilation
This folder contains a tool to help you decompile this web program.
It allows you to:

- Run a local web server
- Decode strings using a pre-decoded array
- And more later!

It uses Node.JS, so ensure that you have that installed on your machine.
In order to run the tool, use `npm test`.

This tool is easy to use, with it's TUI making it very simple to navigate - but the tool is still a **work in progress.**
